# 상품 이미지 주소 설정 (Cloudflare R2)

채널 대량등록 엑셀의 이미지 칸은 **파일이 아니라 인터넷 주소(URL)** 만 받습니다.
`C:/Users/이영주/Desktop/사과.png` 같은 값은 채널 서버가 열 수 없어 등록이 반려됩니다.

이 앱은 사진을 Cloudflare R2에 올리고, 그 주소를 엑셀의 이미지 칸에 자동으로 넣어 줍니다.

---

## 1. 로컬에서 먼저 확인하기

R2 설정을 하지 않아도 **로컬 개발 중에는 그냥 동작합니다.**
Cloudflare 개발 도구가 가짜 버킷을 자동으로 만들어 주기 때문입니다.

```powershell
cd "C:\Users\이영주\Desktop\이왕이\푸르본\스마트스토어 자동화\smartstore-ai"
npm run dev
```

`03 채널별 등록 엑셀 → 이미지 주소 → 사진 인터넷에 올리기` 를 누르면
`http://localhost:5173/api/media/products/...` 같은 주소가 생깁니다.

> **주의**: `localhost` 주소는 내 컴퓨터 안에서만 열립니다.
> 앱이 이 주소를 감지하면 엑셀 내보내기를 막습니다. 실제 등록을 하려면 아래 배포가 필요합니다.

---

## 2. 실제로 쓰려면 — R2 버킷 만들기

1. https://dash.cloudflare.com 접속 → 로그인
2. 왼쪽 메뉴에서 **R2** 클릭
3. 처음이면 R2 사용 시작 절차를 진행합니다 (결제수단 등록을 요구할 수 있습니다. 무료 한도 안에서는 청구되지 않습니다)
4. **Create bucket** → 이름을 정합니다 (예: `damda-media`)
5. 지역(Location)은 기본값 그대로 두면 됩니다

### 무료 한도

| 항목 | 무료 제공 | 초과 시 |
|---|---|---|
| 저장 용량 | 월 10GB | GB당 $0.015 |
| 다운로드(트래픽) | **무제한 무료** | 없음 |
| 쓰기 작업 | 월 100만 건 | 100만 건당 $4.50 |
| 읽기 작업 | 월 1000만 건 | 100만 건당 $0.36 |

상품 100개에 사진 5장씩(장당 1MB)이면 약 500MB로, 무료 한도의 5% 수준입니다.

---

## 3. 앱에 연결하기

`.openai/hosting.json` 의 `r2` 값이 `"MEDIA"` 인지 확인합니다. (이미 설정해 두었습니다)

```json
{
  "project_id": "...",
  "d1": null,
  "r2": "MEDIA"
}
```

배포 환경에서는 이 `MEDIA` 라는 이름에 위에서 만든 버킷(`damda-media`)을 연결하면 됩니다.

---

## 4. 이미지 주소를 짧게 만들고 싶다면 (선택)

기본 주소는 `https://<앱주소>/api/media/products/...` 형태입니다.
`https://img.pureubon.com/...` 처럼 쓰고 싶다면 환경변수 하나만 추가하면 됩니다.

```
MEDIA_PUBLIC_BASE=https://img.pureubon.com
```

앱 코드는 바꿀 필요 없습니다. 이 값이 있으면 그 도메인으로 주소를 만듭니다.

---

## 자주 걸리는 문제

**"이미지 보관소(R2)가 연결되어 있지 않습니다"**
→ `.openai/hosting.json` 의 `r2` 가 `null` 입니다. `"MEDIA"` 로 바꾸고 `npm run dev` 를 다시 시작하세요.

**"채널이 가져갈 수 없는 이미지 주소가 N개 있습니다"**
→ 주소가 `localhost`, `blob:`, 또는 `C:/...` 경로입니다.
　 앱 입력 상품이면 `사진 인터넷에 올리기` 를 누르세요.
　 가져온 엑셀이면 원본 엑셀의 이미지 칸이 컴퓨터 경로라서 그렇습니다. 이 경우 사진을 따로 올린 뒤 엑셀에서 주소를 바꿔야 합니다.

**사진이 10MB를 넘습니다**
→ 장당 10MB 제한입니다. 채널도 대개 비슷한 제한이 있으니 줄여서 올리는 편이 좋습니다.
