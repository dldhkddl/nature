## Cafe24 적용 원칙

미리보기 화면은 최종 디자인과 순서를 먼저 확정하기 위한 코드 화면이다. Cafe24에서는 아래 슬롯별 마크업을 스마트디자인 HTML에 옮기고, 상품 영역의 샘플 데이터만 Cafe24 상품진열 모듈로 교체한다.

| 미리보기 슬롯 | Cafe24 적용 위치 | 적용 방법 |
| --- | --- | --- |
| `header` | 공통 레이아웃 상단 | 로고·검색·회원 메뉴·농산물 단일 내비게이션 유지 |
| `hero` | 메인 페이지 첫 영역 | 자연섬김 PC·모바일 배너 등록 |
| `quick-links` | 메인 배너 아래 | 베스트·제철특가·선물세트·대량구매 링크 연결 |
| `featured-products` | 메인 상품진열 | Cafe24 추천상품/메인진열 모듈로 교체 |
| `season-deals` | 주간 특가 진열 | 별도 상품분류 또는 기획전 상품진열 모듈 연결 |
| `farm-groups` | 상품군별 진열 | 제철 과일·채소/특산물·선물세트 분류별 모듈 연결 |
| `exhibitions` | 기획전 배너 | Cafe24 기획전 또는 프로모션 링크 연결 |
| `brand-story` | 브랜드 소개 | 정적 HTML과 자연섬김 이미지 사용 |
| `trust-guide` | 배송 신뢰 안내 | 정적 HTML 사용, 실제 출고 정책 확정 후 문구 수정 |
| `footer` | 공통 레이아웃 하단 | 고객센터·사업자정보·약관·배송/교환/반품 링크 연결 |

## 상품진열 교체 기준

- 현재 상품 카드 21개는 레이아웃 확인용 샘플이다.
- 상품명, 가격, 할인율, 썸네일, 상세페이지 링크는 Cafe24 모듈 변수를 사용한다.
- 카테고리 내비게이션은 농산물 전문몰에 맞게 다중 식품 카테고리 없이 유지한다.
- 회원 전용 가격은 Cafe24 회원등급 및 할인 정책이 확정된 뒤 실제 표시 조건을 연결한다.

## 적용 전 확인할 운영 정보

- 고객센터 전화번호와 운영시간
- 무료배송 기준 및 기본 배송비
- 제주·도서산간 추가 배송비
- 교환배송비와 반품배송비
- 최종 반품주소
- 사업자정보와 개인정보보호 책임자

## 권장 이식 순서

1. Cafe24 디자인 복사본에서 공통 헤더와 푸터를 적용한다.
2. 메인 페이지에 슬롯 순서대로 정적 섹션을 옮긴다.
3. 네 개의 상품진열 영역을 Cafe24 모듈로 교체한다.
4. 실제 카테고리·기획전·고객센터 링크를 연결한다.
5. PC와 모바일 화면을 확인한 뒤 운영 디자인으로 게시한다.
