# 자연섬김 제철 복숭아 배너 디자인

## 목표

메인 `오늘의 제철 과일` 배너에서 접시 위 초록 포도를 자연섬김 배너 안의 백도 복숭아로 교체하고, 데스크톱 화면의 배너 문구를 왼쪽으로 당겨 여백 균형을 개선한다.

## 이미지 편집

- 편집 대상은 `public/nature-seomgim/hero-pc.png`이다.
- 초록 포도와 포도 잎만 제거한다.
- 같은 배너 오른쪽 과일상자에 있는 백도 복숭아와 동일한 색감·질감의 복숭아 3개를 접시 위에 배치한다.
- 접시, 배경, 오른쪽 과일상자, 식물, 조명은 유지한다.
- 다음 문구와 버튼은 픽셀 형태를 포함해 변경하지 않는다.
  - `산지에서 가장 맛있는 순간`
  - `오늘의 제철 과일`
  - 두 줄 소개 문구
  - `제철 과일 보러가기`

## 화면 위치

- 데스크톱에서는 배너 이미지 표시 위치를 현재보다 약 `64px` 왼쪽으로 이동한다.
- 문구와 버튼도 이미지와 함께 왼쪽으로 이동하되 배너 모서리 안에서 충분한 여백을 유지한다.
- `640px` 이하 모바일에서는 이동값을 해제하고 모바일 전용 배너를 기존 방식으로 표시한다.
- 오른쪽 로그인 카드와 여섯 개 회원 바로가기 위치는 변경하지 않는다.

## 검증

- 배너는 기존 HTML 구조와 Cafe24 `hero` 슬롯을 유지한다.
- CSS에는 데스크톱 왼쪽 이동값과 모바일 해제값이 모두 있어야 한다.
- 빌드와 기존 홈페이지 렌더링 테스트가 통과해야 한다.
