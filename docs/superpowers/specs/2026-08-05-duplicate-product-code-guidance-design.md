# 중복 상품코드 수정 안내 설계

## 목표

상품코드가 중복되었을 때 경고 문장만 보여주지 않고, 사용자가 어떤 상품의 어느 입력값을 고쳐야 하는지 즉시 찾고 수정할 수 있게 한다. 상품코드는 외부 장부나 채널과 연결될 수 있으므로 자동 변경하지 않는다.

## 범위

- 중복된 상품코드별 영향 상품 목록을 전체 경고 바로 아래 표시한다.
- 영향 상품 행을 오류 상태로 강조한다.
- 각 영향 상품에 `수정하기` 동작을 제공한다.
- `수정하기`를 누르면 해당 상품 편집창을 열고 상품코드 입력칸으로 이동해 포커스한다.
- 편집창의 상품코드 입력칸에 오류 테두리와 `다른 상품과 중복된 코드입니다` 안내를 표시한다.
- 상품코드를 바꾸거나 비워 중복이 해소되면 경고, 행 강조, 입력 오류를 즉시 제거한다.

## 화면 흐름

1. `duplicateCodes(products)`로 전체 상품 중 중복 코드를 계산한다.
2. 상단 경고에는 중복 코드만 나열하지 않고 코드별로 영향 상품명과 `수정하기` 버튼을 보여준다.
3. 중복 상품의 목록 행에는 오류 클래스를 적용하고 기존 `코드중복` 배지를 유지한다.
4. `수정하기`는 해당 상품을 편집 대상으로 선택하고 상품코드 필드 이동 요청을 상위 화면에 전달한다.
5. 편집 폼은 현재 상품코드가 중복인지 계산해 입력칸의 `aria-invalid`, 오류 스타일, 도움말을 제어한다.
6. 사용자가 값을 수정하면 기존 상품 저장 흐름이 목록을 갱신하며 중복 상태도 재계산된다.

## 구성요소 경계

### ProductList

- 중복 코드와 해당 상품을 묶어 표시한다.
- 중복된 행에 시각적 오류 상태를 적용한다.
- `onFixDuplicate(id)` 콜백으로 수정 요청만 전달한다.

### Home 편집 화면

- 수정 요청을 받으면 해당 상품을 연다.
- 상품코드 입력 요소를 안정적으로 식별해 화면 이동과 포커스를 수행한다.
- 현재 상품코드가 중복이면 필드 오류 상태와 메시지를 렌더링한다.

### products 유틸리티

- 기존 `duplicateCodes`를 유지한다.
- `duplicateCodeGroups(products)` 순수 함수를 추가해 중복 코드와 영향 상품 ID를 함께 반환한다.
- 목록과 편집 화면은 이 함수의 같은 판정을 사용한다.

## 접근성

- 중복 상품코드 입력에 `aria-invalid="true"`를 적용한다.
- 오류 안내는 입력과 `aria-describedby`로 연결한다.
- `수정하기`는 상품명을 포함한 접근 가능한 이름을 사용한다.
- 색상만으로 오류를 전달하지 않고 배지와 텍스트를 함께 표시한다.

## 오류 처리와 예외

- 빈 상품코드는 중복으로 취급하지 않는다.
- 검색으로 중복 상품 행이 숨겨져 있어도 상단 영향 목록에서 수정할 수 있다.
- 같은 코드가 세 상품 이상에서 사용되어도 모든 상품을 표시한다.
- 사용자가 직접 입력한 상품코드는 자동 생성하거나 자동 변경하지 않는다.

## 테스트

- 코드별 영향 상품을 정확히 묶는 순수 함수 테스트
- 빈 코드를 중복으로 취급하지 않는 테스트
- 세 상품 이상이 같은 코드를 쓸 때 모두 반환하는 테스트
- 목록의 수정 동작이 올바른 상품 ID를 전달하는 UI 동작 확인
- 중복 해소 후 경고와 필드 오류가 사라지는 브라우저 확인

## 완료 조건

- 경고만 보고도 중복된 모든 상품을 식별할 수 있다.
- 한 번의 `수정하기` 동작으로 해당 상품코드 입력칸에 도달한다.
- 중복 상태가 입력칸에서 명확히 표시된다.
- 중복 해소 즉시 모든 관련 오류 표시가 사라진다.
- 기존 상품 선택, 검색, 편집, 저장 흐름이 유지된다.
