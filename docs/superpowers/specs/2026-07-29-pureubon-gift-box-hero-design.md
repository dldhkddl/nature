# 자연섬김 선물상자 배너 디자인

## 목표

메인 `오늘의 제철 과일` 데스크톱 배너에서 접시와 낱개 복숭아를 제거하고, 기존 배너의 복숭아 선물상자를 주 피사체로 재배치한다. 사용자가 직접 조정한 표시 위치에서도 선물상자의 밑부분이 잘리지 않아야 한다.

## 이미지 구성

- 편집 대상은 `public/nature-seomgim/hero-peach-pc.png`의 후속 데스크톱 배너 자산이다.
- 접시와 접시 위 낱개 복숭아 3개를 모두 제거한다.
- 기존 원본 배너 오른쪽에 있던 복숭아 선물상자의 형태, 과일 구성, 포장재, 색감과 질감을 기준으로 사용한다.
- 선물상자를 기존 접시 자리와 배너 오른쪽 영역에 배치한다.
- 상자 전체의 위·아래·오른쪽 모서리가 보이도록 크기를 조절한다.
- 배너 이미지 하단과 선물상자 사이에 약 `25px`의 안전 여백을 둔다.
- 선물상자는 너무 작아 보이지 않도록 배너 오른쪽 영역의 주 피사체 크기를 유지한다.

## 보존 대상

- 다음 왼쪽 문구와 버튼은 픽셀 단위로 보존한다.
  - `산지에서 가장 맛있는 순간`
  - `오늘의 제철 과일`
  - 두 줄의 소개 문구
  - `제철 과일 보러가기` 버튼
- 베이지 배경 질감과 기존 조명을 유지한다.
- 오른쪽 식물과 화병은 가능한 한 그대로 유지한다.
- 모바일용 `hero-mobile.png`는 변경하지 않는다.
- 로그인 카드와 회원 바로가기 영역은 변경하지 않는다.

## 화면 위치

- 사용자가 직접 설정한 데스크톱 CSS 값을 유지한다.

```css
object-position: -100px -20px;
```

- 새 배너는 위 값을 적용한 실제 화면에서도 선물상자 밑부분이 잘리지 않도록 이미지 내부에 안전 여백을 포함한다.
- 모바일에서는 기존 `object-position: center`와 `object-fit: contain`을 유지한다.

## 구현 방식

- 기존 이미지의 선물상자를 기준으로 이미지 편집을 수행한다.
- 완성 자산은 기존 파일을 덮어쓰지 않고 새 파일명으로 저장한다.
- React 구조는 유지하고 데스크톱 이미지 경로만 새 자산으로 교체한다.
- 이미지 크기는 기존 데스크톱 배너와 같은 `1920×400`을 유지한다.

## 검증

- 데스크톱 미리보기에서 선물상자 전체와 하단 안전 여백이 보여야 한다.
- 접시와 낱개 복숭아가 남아 있지 않아야 한다.
- 왼쪽 문구와 버튼 영역은 기존 자산과 동일해야 한다.
- 모바일 배너와 회원 영역은 변경되지 않아야 한다.
- 빌드, 화면 테스트, 스타일 테스트가 통과해야 한다.
