# 4개 입력 기반 채널 자동등록 설계

## 목표

상품마다 사용자가 입력하는 값은 다음 네 가지로 제한한다.

- 상품 이미지
- 판매가
- 상품명
- 용량

프로그램은 이 값과 한 번 저장한 판매자 기본설정을 사용해 네이버 스마트스토어와 카페24의 필수 상품정보를 자동으로 완성한다. 채널 필수값을 확정할 수 없으면 임의 등록하지 않고, 사용자가 이해할 수 있는 한국어 원인과 수정 위치를 표시한다.

## 결정

안전한 완전자동 등록 방식을 사용한다. 네 가지 입력 후 자동 생성과 검증을 모두 통과한 상품은 채널에 바로 등록한다. 검증 실패 상품은 외부 API로 전송하지 않는다.

초기 출시 단계는 소수 상품으로 시험 운영한다. 등록 후 상품을 다시 조회해 상품명, 가격, 재고, 이미지가 요청값과 일치하는지 검증한 뒤 성공으로 처리한다.

## 입력과 자동값

### 상품별 입력

| 입력 | 처리 규칙 |
| --- | --- |
| 상품명 | 입력값을 보존한다. 용량이 상품명에 없을 때만 용량을 한 번 덧붙인다. |
| 판매가 | 쉼표와 원 표시를 제거한 뒤 0보다 큰 정수로 정규화한다. |
| 용량 | kg, g, ml, L, 개입 및 곱셈 구성을 분석해 총용량과 단위가격 정보를 만든다. |
| 이미지 | 첫 이미지는 대표 이미지, 나머지는 추가 이미지 및 상세페이지 이미지로 사용한다. |

### 자동 생성값

- 기본 재고: 30개
- 판매자 상품코드: 상품마다 고유하게 생성하며 네이버 30자 제한과 카페24 40자 제한을 모두 만족한다.
- 원산지: 국산
- 신선 농산물 과세유형: 면세
- 공급가: 별도 원가가 없으면 판매가와 동일하게 설정한다.
- 상품상태: 신상품
- 상세페이지: 이미지, 상품명, 용량 및 저장된 판매자 정보를 이용해 생성한다.
- 배송, 택배사, 반품지, 교환지, AS 전화번호: 판매자 기본설정을 사용한다.
- 카테고리: 상품명과 용량으로 채널별 카테고리를 별도로 탐색한다.

신선 농산물이 아닌 상품으로 판단되거나 카테고리를 확정할 수 없으면 면세나 카테고리를 추측해서 등록하지 않는다.

## 처리 흐름

1. 네 가지 입력을 검사한다.
2. 가격과 용량을 표준 형식으로 정규화한다.
3. 중복되지 않는 판매자 상품코드를 생성한다.
4. 네이버와 카페24 카테고리를 각각 탐색한다.
5. 원산지, 과세, 공급가, 재고, 배송, 고시정보와 단위가격 정보를 생성한다.
6. 이미지를 각 채널의 공식 업로드 API로 전송한다.
7. 채널별 최종 요청을 생성하고 필수값을 다시 검사한다.
8. 검증을 통과한 상품만 등록한다.
9. 반환된 상품번호로 상품을 재조회한다.
10. 상품명, 판매가, 재고, 대표 이미지가 일치해야 성공으로 기록한다.

## 채널 처리

### 네이버 스마트스토어

- 사용자가 입력한 상품명을 유지하고 용량 중복을 방지한다.
- 자동 생성한 판매자 상품코드를 `sellerManagementCode`로 전송한다.
- 카테고리별 필수 고시정보와 단위가격 정보를 생성한다.
- 국산 원산지, 면세, 기본 재고 30개와 저장된 배송 설정을 사용한다.

### 카페24

- 상품 생성에 필수인 상품명과 공급가를 반드시 포함한다.
- 판매자 상품코드를 `custom_product_code`로 전송한다.
- 카페24 전용 카테고리 번호를 `add_category_no`로 전송한다.
- 이미지는 카페24 이미지 업로드 API에 먼저 올리고 반환된 경로를 상품에 연결한다.
- 상품 생성 후 품목 코드를 조회해 재고 사용과 수량 30개를 설정한다.
- 면세 상품은 `tax_type`을 면세로 전송한다.

## 오류와 복구

- 중복 클릭이나 네트워크 재시도로 같은 상품이 두 번 생성되지 않도록 판매자 상품코드를 기준으로 중복을 확인한다.
- 외부 API 오류는 채널, 처리 단계, 잘못된 필드, 해결 방법을 포함한 한국어 메시지로 변환한다.
- 이미지 업로드나 재고 설정 등 중간 단계가 실패하면 성공으로 표시하지 않는다.
- 부분 생성된 상품번호를 기록해 재시도 시 기존 상품을 이어서 보완한다.
- 카테고리 확신도가 낮으면 등록을 중단하고 후보를 표시한다.

## 검증 기준

- 상품명은 입력값과 일치하며 숫자 조각만으로 대체되지 않는다.
- `39,900`, `39900원` 모두 39900으로 등록된다.
- `500g × 4개`는 총 2kg으로 계산된다.
- 판매자 상품코드는 비어 있지 않고 중복되지 않는다.
- 네이버와 카페24에 각각 올바른 카테고리가 사용된다.
- 카페24 공급가가 누락되지 않는다.
- 양 채널 재고는 30개로 설정된다.
- 첫 번째 이미지가 대표 이미지이고 나머지 선택 이미지가 모두 추가 이미지 또는 상세페이지에 반영된다.
- API 실패, 인증 만료, 호출 제한, 중복 요청 및 등록 후 불일치를 테스트한다.

## 출시 조건

단위 테스트와 채널 요청 계약 테스트를 통과한 뒤 채널별 시험 상품 한 개를 등록한다. 시험 상품은 실제 관리자 화면에서 상품명, 가격, 재고, 카테고리, 원산지, 과세, 배송, 이미지와 상세페이지를 확인한다. 이 검증을 통과하기 전에는 여러 상품 일괄등록을 활성화하지 않는다.
