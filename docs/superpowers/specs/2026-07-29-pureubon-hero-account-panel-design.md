# 자연섬김 메인 배너·회원 패널 개선 디자인

## 목표

카테고리 내비게이션과 `지금 많이 찾는 상품` 사이를 식품백억의 메인 구성처럼 정돈한다. 현재 상품 진열 영역과 전체 베이지·그린 브랜드 색상은 유지한다.

## 데스크톱 구성

- 상단 로고는 기존 `오늘도자연섬김` 형태를 유지하되 이미지의 크림색 배경을 제거해 투명 PNG로 사용한다.
- 상단 우측의 `회원가입`과 `로그인`은 간결한 유틸리티 메뉴로 유지한다.
- 검색창 우측에는 아이콘과 명칭이 함께 있는 `전체상품`, `마이페이지`, `장바구니`, `고객센터` 바로가기를 배치한다.
- 카테고리 내비게이션 아래에는 최대 폭이 제한된 2열 메인 영역을 둔다.
- 왼쪽에는 기존 `오늘의 제철 과일` 배너를 넓게 배치한다.
- 오른쪽 위에는 자연섬김 로그인 안내와 로그인 버튼을 담은 짙은 그린 카드가 들어간다.
- 오른쪽 아래에는 `마이페이지`, `주문조회`, `장바구니`, `찜한상품`, `배송조회`, `고객센터`의 2×3 바로가기 패널을 배치한다.
- 이 메인 영역 아래의 `지금 많이 찾는 상품`과 후속 상품 섹션은 현재 구조와 왼쪽 정렬을 그대로 유지한다.

## 모바일 구성

- 로고, 검색창, 회원 바로가기는 세로 흐름으로 정돈한다.
- 메인 배너가 먼저 나오고 로그인 카드와 2×3 바로가기 패널이 그 아래에 이어진다.
- 상품 카드는 기존 2열 반응형 구성을 유지한다.

## 시각 규칙

- 로그인 카드는 자연섬김 그린 `#234837`을 사용한다.
- 바로가기 패널은 밝은 크림 `#f2e7dd` 또는 흰색 바탕과 얇은 베이지 테두리를 사용한다.
- 아이콘은 단순한 선형 SVG로 통일하고 텍스트 레이블을 함께 제공한다.
- 모든 링크와 버튼에는 키보드 포커스 표시를 유지한다.

## Cafe24 이식

- 메인 2열 영역은 `hero-account-panel` 슬롯으로 묶는다.
- 로그인, 마이페이지, 주문, 장바구니, 고객센터 링크는 Cafe24의 실제 회원·주문 URL로 교체할 수 있게 개별 앵커로 유지한다.
- 배너 이미지와 상품진열 모듈은 서로 독립적으로 교체할 수 있어야 한다.

## 검증

- 서버 렌더링 HTML에 로그인 카드와 여섯 개 바로가기 항목이 포함되는지 확인한다.
- 데스크톱 2열과 모바일 1열 반응형 CSS 규칙을 확인한다.
- 전체 빌드와 기존 자연섬김 화면 테스트가 통과해야 한다.
