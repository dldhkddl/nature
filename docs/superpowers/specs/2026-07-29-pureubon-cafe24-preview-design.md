# 자연섬김 푸르본 Cafe24 이식형 홈페이지 디자인

## 1. 목표

식품백억(`https://food100b2b.com/`)의 정보 구성과 상품 탐색 흐름을 참고해 자연섬김 푸르본의 로컬 미리보기 홈페이지를 만든다. 미리보기에서 디자인을 확정한 뒤 Cafe24 스마트디자인 스킨으로 옮긴다.

식품백억의 코드, 문구, 로고, 사진은 복제하지 않는다. 참고 범위는 메뉴 구조, 콘텐츠 순서, 상품 진열 방식과 B2B 쇼핑 흐름이다.

## 2. 제작 원칙

- 제작은 코드 기반으로 진행한다.
- 완성 후 상품, 가격, 재고, 주문, 배너 등 일상 운영은 Cafe24 관리자에서 처리한다.
- 로컬 화면은 Cafe24에 옮기기 쉬운 HTML/CSS 중심 구조로 만든다.
- React 전용 상태나 복잡한 효과처럼 Cafe24 이식에 방해되는 기능은 넣지 않는다.
- 각 화면 구역을 독립적인 섹션으로 만들어 순서와 위치를 쉽게 변경할 수 있게 한다.
- 색상, 최대 너비, 간격, 글꼴 크기는 CSS 변수에 모아 사용자가 나중에 한곳에서 조정할 수 있게 한다.

## 3. 기본 시각 방향

자연섬김의 기존 로고와 배너를 사용하고, 전체 분위기는 따뜻하고 신뢰감 있는 산지 직송 B2B 쇼핑몰로 잡는다.

초기 색상값은 자연섬김 스마트스토어용으로 제작된 `01_프로모션배너_PC_1920x400.png`와 프리미엄 산지직송 최종 시안에서 추출한 값을 사용한다. 모두 CSS 변수로 제공해 나중에 쉽게 조정할 수 있게 한다.

- 바탕 크림: `#F2E7DD`
- 보조 베이지: `#EBE0D4`
- 자연섬김 메인 그린: `#234837`
- 자연섬김 브라운 포인트: `#AB8F70`
- 본문색: `#2B332C`
- 카드 바탕: `#FFFFFF`

사용자가 구체적인 색상과 위치를 조정하므로 구현 단계에서는 장식 효과를 과하게 고정하지 않는다. 상품 사진이 중심이 되도록 여백이 충분한 카드와 절제된 테두리를 사용한다.

## 4. 메인 홈페이지 구성

### 4.1 상단 유틸리티

- 회원가입
- 로그인
- 주문조회
- 고객센터

PC에서는 우측 상단에 배치하고 모바일에서는 메뉴 안에 포함한다.

### 4.2 헤더

- 자연섬김 로고
- 상품 검색창
- 마이페이지
- 장바구니
- 고객센터 바로가기

헤더는 Cafe24 공통 레이아웃으로 옮길 수 있도록 메인 콘텐츠와 분리한다.

### 4.3 카테고리 내비게이션

- 전체상품
- 농산물
- 제철상품
- 선물세트
- 기획전

상품분류는 농산물만 사용한다. 제철상품, 선물세트, 기획전은 다른 식품 대분류가 아니라 농산물 안에서 운영하는 상품 진열 그룹이다. 준비되지 않은 메뉴는 화면에서 숨길 수 있게 한다. 모바일에서는 가로 스크롤 또는 전체 메뉴 형태로 전환한다.

### 4.4 메인 배너

- 기존 자연섬김 PC·모바일 프로모션 배너 사용
- 대표 문구와 버튼 한 개 제공
- PC와 모바일용 이미지를 화면 폭에 따라 교체
- 추후 Cafe24 배너 관리 또는 이미지 교체만으로 운영 가능하게 구성

### 4.5 빠른 이용 메뉴

- 대량구매 문의
- 주문조회
- 배송안내
- 고객센터

식품백억의 셀러용 빠른 메뉴 역할을 자연섬김 운영 방식에 맞게 단순화한다.

### 4.6 인기상품

- 제목: `지금 많이 찾는 상품`
- PC 4열, 모바일 2열
- 기본 8개 상품
- 상품 이미지, 상태 배지, 상품명, 간단 설명, 가격 영역
- 회원 전용 가격을 적용할 경우 비회원에게는 `회원 전용 가격` 문구 표시

### 4.7 산지 특가

- 제목: `산지에서 바로, 이번 주 특별가`
- 베이지 배경으로 인기상품과 구분
- 기본 4~6개 상품
- 특가 또는 제철 배지를 강조

### 4.8 농산물 상품군별 인기상품

제철 과일, 채소·특산물, 선물세트 순서로 구성한다. 모두 농산물 상품 진열이며 각 구역은 소개 문구와 대표 상품 3개를 표시한다. 해당 상품이 없으면 구역 전체를 숨긴다.

### 4.9 기획전

- 제목: `자연섬김 기획전`
- 선물세트, 제철상품, 대량구매 등 운영 중인 기획전을 최대 4개까지 노출
- 상품이 준비되지 않은 초기에는 브랜드 또는 배송 안내 배너로 대체 가능

### 4.10 자연섬김 이야기

- 산지 사진 또는 기존 브랜드 이미지
- 자연섬김의 선별, 품질, 포장 원칙 소개
- 브랜드 소개 또는 게시판으로 이동하는 버튼
- 식품백억의 산지 스토리 역할을 푸르본 브랜드 메시지로 재구성

### 4.11 신뢰 안내

- 산지 직송
- 꼼꼼한 선별
- 안전한 포장
- 신속한 배송

기존 자연섬김 아이콘 자산을 우선 사용한다.

### 4.12 하단 정보

- 고객센터 연락처와 운영시간
- 배송·교환·반품 안내
- 이용약관
- 개인정보처리방침
- 사업자 정보
- 공지사항

실제 정보는 Cafe24 관리자에 등록된 내용을 기준으로 연결한다.

## 5. Cafe24 이식 구조

| 로컬 미리보기 | Cafe24 적용 방식 |
|---|---|
| 공통 헤더와 하단 | 사용 중인 스킨의 공통 레이아웃 파일 |
| 메인 콘텐츠 | 메인화면 `index.html` |
| 검색창 | Cafe24 검색 모듈 |
| 카테고리 메뉴 | Cafe24 상품분류 모듈 |
| 인기·특가·카테고리 상품 | Cafe24 메인 상품진열 모듈 |
| 로그인·회원·장바구니 | Cafe24 회원 및 주문 링크·모듈 |
| 배너와 브랜드 이야기 | 직접 편집 가능한 HTML 및 이미지 영역 |
| 색상·간격·반응형 스타일 | 스킨 CSS 파일 |

Cafe24 스킨마다 실제 파일 경로와 모듈 ID가 다를 수 있다. 이식할 때 현재 사용 중인 스킨을 먼저 복사한 뒤, 해당 스킨에서 제공하는 파일과 모듈을 확인해 연결한다.

## 6. 데이터 흐름

로컬 미리보기에서는 실제 Cafe24 API를 사용하지 않고 예시 상품 데이터와 기존 브랜드 자산을 사용한다. Cafe24 이식 단계에서 예시 상품 카드를 상품진열 모듈로 교체한다.

상품 카드의 바깥 레이아웃과 CSS 클래스는 유지하고, 상품명·가격·이미지·상세 링크만 Cafe24 모듈 데이터가 출력하게 한다. 주문, 결제, 회원가입, 마이페이지는 Cafe24 기본 페이지로 연결한다.

## 7. 반응형 기준

- PC: 헤더 검색 중심, 상품 4열, 넓은 배너
- 태블릿: 상품 3열, 축소된 메뉴
- 모바일: 상품 2열, 모바일 배너, 접이식 전체 메뉴
- 가로 넘침이 없어야 하며 버튼과 메뉴는 터치하기 충분한 크기를 유지한다.

## 8. 예외 처리

- 상품이 없는 진열 구역은 빈 카드 대신 구역 전체를 숨긴다.
- 이미지가 없으면 자연섬김 기본 대체 이미지를 사용한다.
- 긴 상품명은 카드 높이를 깨뜨리지 않도록 두 줄까지만 표시한다.
- Cafe24에서 지원하지 않는 로컬 효과는 제거하고 기본 링크 이동을 우선한다.

## 9. 이번 제작 범위

포함:

- 메인 홈페이지 로컬 미리보기
- PC·모바일 반응형 화면
- Cafe24 이식을 고려한 섹션 분리
- 기존 자연섬김 로고, 배너, 아이콘 적용
- 예시 상품과 실제처럼 보이는 문구

제외:

- Cafe24 실제 스킨 이식
- 주문서와 결제 화면 커스텀
- Cafe24 API 연동
- 실제 상품 등록
- B2B 회원등급 및 회원별 가격 기능 개발

## 10. 완료 기준

- 식품백억과 유사한 상품 탐색 흐름을 갖되 자연섬김 브랜드로 구분되어야 한다.
- 베이지·그린 색감과 기존 자연섬김 자산이 일관되게 적용되어야 한다.
- PC와 모바일에서 핵심 콘텐츠가 자연스럽게 보여야 한다.
- 각 섹션의 위치와 색상값을 사용자가 쉽게 수정할 수 있어야 한다.
- Cafe24 상품·검색·회원 모듈로 교체할 위치가 명확해야 한다.
- 로컬 미리보기에서 모든 링크와 버튼이 예상된 위치에 표시되어야 한다.
