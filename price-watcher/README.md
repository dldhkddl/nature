# price-watcher — 주단가 엑셀 → 변동 추출 · 판매가 계산 · 품절 감시

농장에서 매주 오는 **주단가 엑셀** 한 장을 넣으면,
지난주와 비교해 **무엇이 바뀌었는지**(공급가·품절·신규·단종)를 뽑고,
스마트스토어/쿠팡 **권장 판매가와 예상 마진**까지 계산해 목록으로 내놓는다.

웹앱(등록기)과 분리된 **독립 배치 스크립트**다. 주 1회 돌리는 게 전부다.

## 설계 핵심: 어댑터 방식 (config.json)

농장 엑셀은 형식이 조금씩 흔들린다(헤더 이름이 '공급가'였다가 '주단가'가 되고, 열 순서가 바뀌고…).
그래서 코드는 컬럼 위치를 하드코딩하지 않고, **`config.json`이 어댑터 역할**을 한다.
마치 나라마다 다른 콘센트에 맞추는 **여행용 멀티어댑터**처럼 —
플러그(엑셀 헤더) 모양이 바뀌면 코드는 그대로 두고 `config.columns`에 **별칭 하나만 추가**하면 된다.

```json
"columns": {
  "supply": ["공급가", "주단가", "단가", "매입가", "원가"]
}
```

## 실행 방법

```bash
# 최초 1회 설치
npm install

# 두 파일을 직접 비교
node run.mjs --prev 지난주.xlsx --curr 이번주.xlsx

# 매주 실전: 이번주 파일만 주면 지난주 스냅샷(out/latest.json)을 자동으로 전주로 사용
node run.mjs --curr 이번주.xlsx

# 가짜 샘플로 한 번에 데모
npm run demo
```

## 결과물 (`out/` 폴더)

| 파일 | 내용 | 용도 |
|---|---|---|
| `change-report_<날짜>.md` | 품절·가격변동·신규·단종·재입고 전체 요약 | 사람이 보고 판단 |
| `price-updates_<날짜>.csv` | 가격변동+신규 품목의 마켓별 권장판매가·마진 | 가격 반영 목록 |
| `stock-actions_<날짜>.csv` | 판매중지/재개 대상 | 품절 처리 목록 |
| `latest.json` | 이번 주 스냅샷 | 다음 주 비교 기준(자동) |

> **지금은 '목록만' 생성한다.** 마켓에 자동으로 밀어넣지 않는다.
> 효과를 눈으로 검증한 뒤, 커머스API(스마트스토어)·Wing API(쿠팡)로 자동 반영을 붙인다.

## 판매가 계산식

```
판매가 × (1 − 수수료율 − 목표마진율) = 공급가 + 배송비
→ 판매가 = (공급가 + 배송비) / (1 − 수수료율 − 목표마진율)
```

수수료를 떼이고 목표 마진을 남기고도 공급가를 커버하는 최소 판매가를 역산한 뒤 100원 단위로 올린다.
수수료율·마진율·반올림 단위는 모두 `config.json`의 `pricing`에서 조정한다.
(현재 기본값: 스마트스토어 수수료 5.6%, 쿠팡 10.8%, 목표마진 15% — **실제 계약 수수료로 반드시 교체할 것**)
